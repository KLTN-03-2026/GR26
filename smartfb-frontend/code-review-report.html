CriticalJWT secret có fallback production-grade hardcodedSpring Boot
Vị trí: ../Smartfnb-BE/src/main/resources/application.yml:73

JWT secret đang có default cố định trong config. Nếu deploy thiếu biến môi trường, tất cả access/refresh token sẽ được ký bằng secret public trong repo, tạo lỗ hổng giả mạo token.

❌ Hiện tại

jwt:
  secret: ${JWT_SECRET:SmartFnbSuperSecretKey2026ChangeInProduction!@#$%^&*()}
  expiration-ms: ${JWT_EXPIRATION_MS:3600000}

✅ Đề xuất

jwt:
  secret: ${JWT_SECRET}
  expiration-ms: ${JWT_EXPIRATION_MS:3600000}

# fail-fast bằng @ConfigurationProperties + @NotBlank + min entropy

STOMP endpoint dùng setAllowedOriginPatterns("*"). Dù CONNECT frame có JWT interceptor, wildcard origin mở rộng bề mặt tấn công CSRF-like WebSocket, token leakage qua browser extension và abuse từ domain không kiểm soát.

MajorCPU-bound fit/predict block event loopFastAPI/AI
Vị trí: ../ai-service/app/services/train_service.py:421 và ../ai-service/app/services/predict_service.py:419

Các hàm async gọi trực tiếp model.fit() và model.predict(). Đây là tác vụ CPU-bound/PyTorch blocking; khi chạy trong FastAPI BackgroundTasks hoặc scheduler cùng process, event loop có thể bị nghẽn và health/API bị chậm.
