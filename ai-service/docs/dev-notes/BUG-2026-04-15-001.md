# BUG-2026-04-15-001: data_service.py — function name mismatch

## Mô tả
`train_service.py` import 2 functions không tồn tại trong `data_service.py`:
- `get_active_tenants` (tên thật: `get_all_active_tenants`)
- `get_all_consumption_for_tenant` (chưa implement)

`test_data_service.py` cũng test 5 functions chưa có:
- `_build_and_fill`, `get_active_ingredients`, `get_active_tenants`, `get_branch_coordinates`, `get_recent_consumption`

## Root Cause
Test file và train_service.py được viết trước (hoặc riêng biệt) với data_service.py thực tế, dùng naming convention khác nhau.

## Cách fix
Thêm vào `data_service.py`:
1. `get_active_tenants` — alias của `get_all_active_tenants`
2. `get_branch_coordinates(db, branch_id)` — query lat/lng từ branches
3. `get_recent_consumption(db, series_id, days)` — query consumption_history
4. `_build_and_fill(day_rows, start_date, series_id)` — pure function tạo DataFrame đầy đủ ngày
5. `get_active_ingredients(db, tenant_id, branch_id)` — kèm series_id từ registry
6. `get_all_consumption_for_tenant(db, tenant_id, days_back)` — cho train job

Import `SeriesRegistryRepo` ở module level (không lazy import) để patch test hoạt động.

## Files bị ảnh hưởng
- `app/services/data_service.py` (sửa)
- `app/services/train_service.py` (fix imports)
- `tests/test_data_service.py` (fix asyncio marks)
